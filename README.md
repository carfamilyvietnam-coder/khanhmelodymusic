# KhanhMelody - Trình phát nhạc

Trình phát nhạc đơn giản và hiện đại được xây dựng bằng Python với giao diện Tkinter và pygame.

## Tính năng

- 🎵 Phát các định dạng nhạc phổ biến (MP3, WAV, OGG, M4A)
- 📂 Thêm nhiều file nhạc cùng lúc
- ⏮⏭ Chuyển bài trước/tiếp theo
- ⏸ Tạm dừng và tiếp tục phát
- 🗑 Xóa danh sách phát
- 🎨 Giao diện đẹp mắt với màu sắc hiện đại
- 📊 Hiển thị trạng thái phát nhạc

## Cài đặt

### Yêu cầu

- Python 3.7 trở lên
- pip

### Cài đặt dependencies

```bash
pip install -r requirements.txt
```

## Chạy ứng dụng

```bash
python src/main.py
```

## Hướng dẫn sử dụng

1. **Thêm nhạc**: Nhấn nút "📂 Thêm nhạc" và chọn file nhạc từ máy tính
2. **Phát nhạc**: Chọn bài hát trong danh sách và nhấn "▶ Phát"
3. **Điều khiển**: Sử dụng các nút để tạm dừng, dừng, chuyển bài
4. **Xóa danh sách**: Nhấn "🗑 Xóa hết" để xóa toàn bộ danh sách phát
